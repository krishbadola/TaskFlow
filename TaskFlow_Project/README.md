# TaskFlow – Personal Task Manager

## Run the project
1. Extract the ZIP file.
2. Open the `TaskFlow_Project` folder in VS Code.
3. Open `index.html` in your browser (or use the VS Code Live Server extension).
4. Add tasks, edit them, mark them complete, search and filter.

## Features
- Create, edit and delete tasks
- Mark tasks as completed
- Search by task name
- Filter all, pending and completed tasks
- Dashboard counters
- LocalStorage persistence (tasks remain after refresh in the same browser)
- Responsive layout

## Technologies
HTML5, CSS3, JavaScript (DOM, events, arrays, objects, LocalStorage).

## Important
This is a front-end demonstration project. Data is saved in the browser only; it does not use a server, database, or user login.
